## Описание программы "Тест реальности" для Lolin 8266 Arduino
### 📄 **Техническое задание: Программа "Тест на реальность"**

---

## 🔧 1. Описание программы

Программа предназначена для работы с микроконтроллером (например, ESP8266 или ESP32), подключённым к OLED-дисплею SSD1306 и двум кнопкам. Она реализует функционал таймера с возможностью отслеживания нажатий пользователем, отображением статистики, а также проигрыванием мелодии при истечении времени.

---

## 🎯 2. Цель программы

Создать устройство, которое:
- Считает количество нажатий на первую кнопку.
- Отслеживает средний интервал между нажатиями.
- Ведёт обратный отсчёт до сигнала по выбранному таймеру.
- При истечении времени таймера воспроизводит мелодию.
- Позволяет пользователю переключать длительность таймера.
- Обладает визуальным оформлением с прокручивающимся заголовком.

---

## 🧩 3. Функциональные требования

### ✅ 3.1. Устройства и датчики
| Компонент | Назначение |
|----------|------------|
| OLED SSD1306 (128x64) | Вывод информации на экран |
| Кнопка D6 | Счётчик нажатий |
| Кнопка D7 | Выбор таймера / тест мелодии |
| Пьезо-излучатель (D5) | Звуковой сигнал |

---

## 📋 4. Основная функциональность

### 4.1. Счётчик нажатий
- При каждом нажатии на кнопку D6:
  - Увеличивается счётчик `pressCount`.
  - Проигрывается короткий звуковой сигнал.
  - Рассчитывается и сохраняется временной интервал между нажатиями (`pressIntervalSum`).

### 4.2. Статистика
На экране отображаются:
- Текущее количество нажатий.
- Среднее время между нажатиями (в формате `чч:мм:сс`).
- Время с момента последнего нажатия (в формате `чч:мм:сс`).

### 4.3. Таймер
- Доступны три варианта длительности таймера:
  - 60 минут
  - 30 минут
  - 10 минут
- По умолчанию установлен таймер на 60 минут.
- По истечении времени таймера:
  - Проигрывается мелодия.
  - Таймер автоматически перезапускается с тем же интервалом.

### 4.4. Переключение таймера
Кнопкой D7 можно:
- Кратковременное нажатие (<2 сек): переключить таймер на следующую длительность.
- Долгое нажатие (≥2 сек): запустить тест мелодии вручную.

### 4.5. Мелодия
- Проигрывается мелодия из файла `bohemian_rhapsody.h` (или другой мелодии, если файл заменён).
- Используется функция `tone()` для генерации звука через пьезо-излучатель.

### 4.6. Экран
- Прокручивающийся заголовок программы ("Тест на реальность") в верхней части экрана.
- Информационные данные ниже:
  - Счётчик нажатий
  - Средний интервал
  - Время с последнего нажатия
  - Таймер и оставшееся время

**Элементы экрана:**
- Прокручивающийся заголовок программы.
- Линия-разделитель.

- Строка со средним интервалом между нажатиями.

- Строка с текущим таймером и оставшимся временем.

## 🧠 6. Особенности реализации

### 6.1. Русский язык на экране
- Реализована функция `utf8rus()` для конвертации строк из UTF-8 в CP1251, используемый библиотекой Adafruit_SSD1306.
- Универсальная функция `printFormatted()` позволяет выводить локализованные строки с переменными значениями (аналог `printf()` для русского языка).

### 6.2. Прокрутка текста
- Реализована анимация горизонтальной прокрутки заголовка влево и вправо.

### 6.3. Автоматический перезапуск таймера
- После окончания таймера он сразу перезапускается с тем же интервалом.

## 📐 7. Архитектура программы

```
setup()
├── Инициализация последовательного порта
├── Настройка пинов (кнопки, пищалка)
├── Инициализация OLED-дисплея
└── Установка начального таймера

loop()
├── checkMainButton() — обработка нажатий на основную кнопку
├── checkSelectButton() — выбор таймера или тест мелодии
├── checkAlarm() — проверка истечения таймера
└── updateDisplay() — обновление данных на экране
```

---

## 📌 8. Дополнительные примечания

- Для корректного отображения кириллицы используется кодировка CP1251.
- Мелодия хранится в отдельном файле `bohemian_rhapsody.h`, который должен содержать массивы частот и длительностей.
- В случае ошибки инициализации дисплея программа зависает (без дисплея не работает).

## 📦 9. Требования к оборудованию

| Компонент | Пин | Описание |
|----------|-----|----------|
| OLED SSD1306 | I2C (SCL, SDA) | Поддержка напряжения 3.3V |
| Кнопка 1 | D6 | INPUT_PULLUP |
| Кнопка 2 | D7 | INPUT_PULLUP |
| Пьезо-излучатель | D5 | OUTPUT |
| Питание дисплея | D8 | HIGH (если нужно дополнительное питание) |

## 🏁 11. Заключение

Программа "Тест на реальность" представляет собой комбинированное устройство, сочетающее элементы учёта активности пользователя, таймера и медиа-проигрывателя. Может быть использована как экспериментальный проект, демонстрация возможностей микроконтроллера или часть более сложной системы взаимодействия с пользователем.


### Заключение
Программа "Тест реальности" является простым и эффективным инструментом для измерения времени между событиями. Возможность очистки логов делает её удобной для многократного использования.
